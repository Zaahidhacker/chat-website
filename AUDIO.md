# Private audio update

Voice notes: up to 60 seconds, requested 24kbps mono, native WebM/Opus or AAC fallback. Maximum recording 195KB, maximum 200 pending/live recordings to bound database growth (~52MB base64 ceiling). These deliberately small recordings are stored separately in Postgres, fetched only on playback. RLS restricts access to members with a visible, nondeleted chat message and an unexpired recording. Playback expires immediately after 48h by server policy; physical deletion runs each minute through pg_cron. Chat message placeholders persist. No claims of preventing a recipient recording or retaining audio already received. Notes are not end-to-end encrypted. Draft recording is memory-only, cancelled on closing; failed sends can retry while the dialog is open, using the same UUID. No offline persistence of recordings.

Calling was removed from the UI, JavaScript bundle and listeners on November 3 at the owner's request. No call signaling channel is subscribed to and the client no longer requests microphone access for calls. Voice notes continue to request permission only when recording. Previously created backend tables are retained to avoid changing personal data; their existing cleanup job remains active. There is no TURN setup requirement for voice notes.

Validation: 49 unit tests, 18 messaging and 9 overhaul browser scenarios passed; focused recording/preview/send/receive-decode/cancel and WebRTC offer/answer/mute/remote-hangup passed in Chromium using synthetic microphones and controlled signaling. Managed Chromium WebRtcIPHandling=disable_non_proxied_udp blocks actual ICE audio connectivity here; actual mobile calls, Safari audio and TURN remain unverified. Do not describe this as fully stable production calling. Server expiry job active; deletion test transaction was not executed because confirmation expired. New guarded SECURITY DEFINER send RPC is intentional (matching the existing atomic send boundary), checks membership and bounded payload and pins empty search_path; advisor flags signed-in execute as expected.

Private pre-change backup verified: 9968 messages,36 photos,2 member identities, stored in ignored work/pre-audio-backup.json with0600 mode. No historical chat/photo/account/game data changed. Migration adds two tables, one RPC, RLS and a cron job. No old table changes.


The redesigned audio test now covers only recording, preview, send, receive/decode, and cancellation. The earlier WebRTC test is historical; calling is no longer a shipped feature.
