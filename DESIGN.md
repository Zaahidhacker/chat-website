# Dreamy baby-pink reference redesign

The supplied November 3 reference contains desktop and phone HTML for chat and sign-in. The desktop login HTML is retained as an inert template, with a single responsive form (no duplicated IDs or separate hidden authentication forms). Its inputs, password visibility button, invitation setup, sample preview and ambience control are connected to the existing application. Layout interpolates to a tablet and the compact supplied phone direction. Poppins and Caveat are served locally; Cormorant provides the reference's serif hierarchy. Tailwind/PostCSS compile the supplied utility classes at build time only: no Tailwind CDN, font CDN, remote icon script or inline event handler ships.

The conversation retains its existing functional DOM, realtime subscriptions and bounded history. Sidebar, dark/pink palette, glass header, blush bubbles, polaroid capsule, composer and mobile space navigation follow the supplied visual structure. Real account names, presence and keepsake count replace the mock values. Existing photos, replies, links, voice notes, settings, private locations, Pip/garden, island, heart secret and anniversary story remain connected. Sidebar scrollbars stay hidden while touch, wheel and keyboard scrolling work. Day counts and presence are independent: no invented location, local-time or online claim from the sample HTML.

The day counter reports **elapsed calendar days** since September 27, 2026 in Asia/Colombo. The start date is 0, September 28 is 1, and November 3 is 37. There is a single midnight timer plus a visibility recheck, with no polling or database requests. Tests cover both sides of Colombo midnight and dates supplied with different offsets.

Wishing-star charms prepare an unsent draft. Thinking-of-you charms and the daily capsule open the existing personal note picker. Users can pause floating decorations; the setting persists. Transform/opacity animations pause when hidden and respect reduced motion. Animation of glow filters from the static reference was replaced with constant lighting to reduce painting cost. The Remember our world checkbox controls local versus tab-session authentication storage; unchecked sessions survive reload in the same tab, and are absent in a new tab. No password is stored by this control.

Calling is removed: no call controls, source bundle, signaling subscription or call microphone request. Existing backend data and the earlier expiry job are retained. Voice notes still work separately. No database, Supabase account, storage or game-progress migration was performed for this redesign.

The new chat styles load with the existing signed-in view and are awaited before its first render, preventing a layout flash and preserving the first scroll position. The cold entry JS/CSS remains below the unchanged 25,000-byte gzip guard. Tests use synthetic accounts and deterministic transport; no private messages were sent or modified to test the redesign. Physical Android/iPhone and live-network delivery are not established by these fixtures.

## Reliability and readability polish — November 3, 2026

The supplied baby-pink/Poppins/Caveat design and existing navigation remain. Voice dialogs now have a distinct heart mark, a readable recording clock, native playback, size/duration details and a clear re-record/send hierarchy. The clock is hidden from the accessibility tree so its one-second updates do not repeatedly announce over the recording instructions. Mobile inputs use 16px text to avoid iOS focus zoom. Light-theme sidebar labels and phone message actions have stronger contrast; dialogs use their visible heading as an accessible name and keep native media controls in the keyboard focus sequence.

Search operates on loaded messages without extra database requests. Its compact result cards show author and time, safely highlight matching text, keep long messages to contextual snippets, and return to the chosen message with a temporary outline. Closed or superseded lazy-loaded dialogs cannot reopen after a slow import finishes. Existing games, personal content, reply spacing and reduced-motion behavior are preserved.

Signed-in icon paths now load with the conversation; the public login retains only the two paths it can need before sign-in. All 24 original paths are unchanged. Initial JavaScript and CSS total 24,128 bytes gzip under the unchanged 25,000-byte guard. The new axe-core dependency is a development-only accessibility test tool and is not bundled into the site.
